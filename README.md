# SEMI - 인사 및 연차 관리 시스템

## 1. 프로젝트 소개

직원의 일정과 근태 및 연차를 관리하기 위한 웹 기반 업무 관리 시스템입니다.

Spring MVC 기반 웹 애플리케이션의 데이터 처리 흐름을 이해하고, CRUD 기능과 일정 관리 기능을 구현하는 것을 목표로 진행했습니다.

- **프로젝트 기간:** 2026.05.26 ~ 2026.06.23
- **프로젝트 유형:** 팀 프로젝트
- **담당 역할:** 팀장 및 주요 기능 구현

## 2. 기술 스택

- **Backend:** Java, Spring
- **Database:** Oracle
- **Frontend:** HTML, CSS, JavaScript
- **Library:** FullCalendar
- **Tools:** STS4, Visual Studio Code, DBeaver, Git, GitHub

## 3. 주요 기능

### 일정 관리
- FullCalendar를 활용한 일정 조회 및 관리
- 전체·부서별·개인별 일정 구분
- 모달을 활용한 일정 등록, 수정 및 상세 조회
- 비동기 처리를 통한 페이지 이동 없는 일정 갱신

### 연차 관리
- Spring Scheduler를 활용한 자동 연차 부여
- 입사일과 근속 기간에 따른 연차 계산 로직 구현
- 근속 기간에 따른 연차 발생 및 증가 규칙 적용

### 공통 기능
- 회원 데이터 조회 및 CRUD 기능 구현
- 공통 AOP 및 접근·근태 로그 관련 기능 구현
- GitHub를 활용한 소스 코드 관리 및 팀 협업

## 4. 담당 업무

- 팀장으로서 GitHub 저장소 관리 및 작업 일정 조율
- 회원 데이터베이스 구성 및 CRUD 기능 구현
- FullCalendar 기반 일정 관리 기능 구현
- 모달과 비동기 요청을 활용한 일정 등록·수정·상세 조회 구현
- Spring Scheduler를 활용한 자동 연차 부여 로직 구현
- 공통 기능 및 화면 스타일 구현 지원

## 5. 주요 구현 내용

### FullCalendar 기반 일정 관리

전체·부서별·개인별 일정을 구분하고, 모달과 비동기 요청을 활용해 일정 등록·수정·상세 조회가 가능하도록 구현했습니다.

이를 통해 페이지 이동을 최소화하면서 일정 데이터를 조회하고 변경하는 웹 기능을 구현했습니다.

### 자동 연차 부여

Spring Scheduler를 활용해 입사일과 근속 기간을 기준으로 연차를 계산하고 부여하는 기능을 구현했습니다.

연차 발생 규칙을 코드로 구성하면서 날짜 계산과 조건별 데이터 처리의 중요성을 학습했습니다.

## 6. 프로젝트 회고

프로젝트 진행 중 요구사항이 변경되면서 일정의 유형과 적용 범위를 구분해야 하는 상황을 경험했습니다. 이를 통해 초기 데이터 구조를 설계할 때 향후 기능 확장 가능성까지 고려해야 한다는 점을 배웠습니다.

또한 GitHub 병합 과정에서 발생한 코드 유실 문제를 계기로 작업 브랜치 분리, 일일 진행 상황 공유, 병합 이후 통합 테스트의 중요성을 경험했습니다.
